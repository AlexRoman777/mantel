# Generated Instant backgrounds

These private Mantel assets were created as original photorealistic material
artwork with OpenAI's built-in image generator on 2026-09-04. They were not
downloaded from a texture library and are bundled locally with the application.

Every listed JPEG is exported at exactly 3840 x 2160:

- `red-velvet-4k.jpg` - deep ruby velvet
- `bronze-copper-4k.jpg` - dark hand-patinated bronze and copper
- `travertine-4k.jpg` - honed ivory travertine
- `carrara-marble-4k.jpg` - warm Calacatta-style marble
- `blue-onyx-4k.jpg` - translucent Azuli blue onyx
- `metal-mesh-4k.jpg` - black architectural woven metal mesh
- `indigo-plaster-4k.jpg` - midnight indigo lime plaster
- `dark-terrazzo-4k.jpg` - honed charcoal terrazzo

The artwork contains no remote dependencies, logos, text, or family media.
Mantel's normal OLED background-rest behavior applies to all of these surfaces.
